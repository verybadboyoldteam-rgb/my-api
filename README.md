# API с авторизацией и управлением сессиями

Сервис возвращает персонализированный JSON-ответ с информацией о пользователе. Доступ защищён уникальными токенами, которые выдаются при каждом входе.

## 👤 Для пользователей

1. Откройте страницу входа.
2. Введите логин `admin` и пароль `12345`.
3. Нажмите «Получить данные».
4. Вы увидите JSON с данными и информацией о сессии.
5. Кнопка «Выйти» завершает сессию — после этого токен перестаёт работать.

---

## 👨‍💻 Для разработчиков

### Авторизация

- При входе создаётся уникальная сессия и выдаётся Bearer-токен.
- Токен передаётся в заголовке `Authorization: Bearer <token>`.
- Каждая сессия хранит данные об устройстве, IP-адресе и времени входа.

### Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/login` | Вход (логин и пароль в теле) |
| GET | `/api` | Получение данных (требуется токен) |
| POST | `/logout` | Выход (завершает текущую сессию) |
| GET | `/sessions` | Список активных сессий |
| DELETE | `/sessions/{id}` | Завершение сессии по ID |
