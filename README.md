# API с авторизацией

Сервис возвращает JSON с данными пользователя.

**Ссылка на сервис:** https://my-api-pde9.vercel.app

## Простой способ проверить (для людей)
Просто открой ссылку в браузере, введи логин `admin` и пароль `12345` и нажми кнопку — ты увидишь JSON с данными.

## Для разработчиков (программный доступ)
- **Токен:** `leha_krepko_divigatesya` (передавай в заголовке `Authorization: Bearer ...`)
- **POST-запрос:** на `/api` с телом `{"login":"admin","password":"12345"}`

При ошибке — ответ `401 Unauthorized`.
