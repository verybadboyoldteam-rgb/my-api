# API с персонализированными данными

Это мини-сервис, который возвращает JSON с данными о заказчике.

## Ссылка на работающий сервис
[https://my-api-pde9.vercel.app/api](https://my-api-pde9.vercel.app/api)

## Ответ сервера
- **name** (string) — Имя заказчика
- **age** (number) — Возраст
- **profession** (string) — Должность
- **hobbies** (array) — Список увлечений
- **location** (object) — Текущая и желаемая страна

## Технологии
- JavaScript (Node.js)
- Vercel (Serverless Functions)
- GitHub
