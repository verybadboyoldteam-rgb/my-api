# API с авторизацией для заказчика

Этот сервис возвращает персонализированный JSON-ответ. Доступ защищён двумя способами авторизации.

---

## 🔗 Ссылка на работающий сервис
[https://my-api-pde9.vercel.app/api](https://my-api-pde9.vercel.app/api)

---

## 📦 Что возвращает API

| Ключ | Тип | Пример значения |
|------|-----|-----------------|
| `name` | строка | "Алексей" |
| `age` | число | 35 |
| `profession` | строка | "Руководитель отдела мобильной разработки" |
| `hobbies` | массив строк | ["менять скины в Quake 3", ...] |
| `location` | объект | { "currentCity": "Минск", ... } |
